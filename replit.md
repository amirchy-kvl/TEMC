# TEMC — The Eureka Marketing Co.

A multi-page static website for The Eureka Marketing Co., a Bangladesh aquaculture solutions company established in 2001.

## Stack
- **Vite** (v5) — dev server and bundler
- Plain HTML, CSS, JavaScript — no frontend framework

## Pages
- `index.html` — Home
- `about.html` — About
- `products-services.html` — Products & Services
- `history.html` — History
- `recognition.html` — Recognition
- `gallery.html` — Gallery

## Running locally on Replit
```
npm run dev
```
Serves on port 5000 via the "Start application" workflow.

## Build for production
```
npm run build
```
Outputs to `dist/`.
